# Wood Screw Master

A photorealistic, highly engaging React puzzle game built with Tailwind CSS, Lucide React icons, and Web Audio API synthesis.

## Features
- **Photorealistic Visuals**: SVG-based metallic screw head details, layered wood textures, drop shadows, and bevel filters.
- **Dynamic Gravity & Swing Physics**: Plates swing realistically when partially unscrewed and fall when all anchoring screws are removed.
- **Synthesized Audio**: Web Audio API generates unscrew clicks, storage clinks, wood drop thuds, victory fanfares, and error chimes without external audio assets.
- **Full Navigation**: Interactive **Puzzle**, **Badges/Achievements**, and **Rules** tabs.
- **Level Progression & Power-ups**: Hint system, Undo stack, coin tracking, level timer, and star rewards.

## Setup Instructions

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```
